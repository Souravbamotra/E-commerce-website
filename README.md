# Anime & Pop Culture E-Commerce Website

An interactive e-commerce web application featuring anime and pop culture merchandise, apparel, action figures, lamps, wall art, and accessories.

## 🚀 Features

- **Storefront & Catalog**: Explore featured collections, new drops, sale items, and categorized merchandise.
- **Product Details**: High-resolution image showcases, pricing, item descriptions, and stock status.
- **Cart & Checkout**: Interactive shopping cart management and streamlined checkout flow.
- **User Account & Order Tracking**: Profile management, order tracking, and wishlist.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
